\# Amazon E-Commerce Sales Analysis \& Dashboard



\## 📌 Project Overview



This project analyzes Amazon e-commerce sales data to understand sales performance, order trends, product performance, customer order patterns, and regional sales distribution.



The project uses Python for data cleaning and exploratory data analysis (EDA), and Microsoft Power BI to create an interactive dashboard for visualizing key business insights.



\---



\## 🎯 Objectives



The main objectives of this project are



\- Clean and preprocess the raw Amazon sales dataset

\- Analyze sales and order trends over time

\- Understand product and category performance

\- Analyze sales across different Indian states

\- Analyze order status and fulfilment patterns

\- Identify important business metrics such as revenue, average order value, and cancellation rate

\- Build an interactive Power BI dashboard for business analysis

\## 🔄 Project Workflow



\### 1. Data Collection



An Amazon India e-commerce sales dataset containing order, product, sales, quantity, location, fulfilment, and order status information was used for the analysis.



\### 2. Data Cleaning



The dataset was cleaned using Python and Pandas.



The cleaning process included



\- Handling missing values

\- Removing duplicate records

\- Standardizing column names

\- Standardizing text values

\- Correcting inconsistent location names

\- Removing invalid state records

\- Preparing date and numerical columns for analysis



\### 3. Exploratory Data Analysis



Python was used to explore the dataset and understand



\- Sales trends

\- Order quantities

\- Product categories

\- Order status

\- Regional distribution

\- Product sizes

\- Other relevant sales patterns



\### 4. Power BI Dashboard



The cleaned dataset was imported into Power BI and transformed into an interactive dashboard containing KPIs, charts, maps, slicers, and other visualizations.
